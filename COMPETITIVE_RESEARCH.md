# SkyTrack — Competitive Research Report

## Top Flight Tracking Apps (2025–2026)

### Market Overview

The flight tracking app market is bifurcated into two segments:
1. **Aviation Enthusiast Apps** (Flightradar24, Plane Finder, RadarBox) — comprehensive global tracking, AR views, deep aircraft data
2. **Traveler-Focused Apps** (Flighty, byAir, KAYAK) — personal trip management, delay prediction, actionable alerts

**Key Market Trends**:
- AI/ML is the new frontier: delay prediction, airport guides, price checking
- "Enshittification" of legacy apps (excessive ads, reduced free features) is creating opportunity for premium, ad-free alternatives
- App in the Air shut down (Oct 2024), leaving a gap byAir and Flighty are filling
- Space-based ADS-B (Aireon/Spire) has made truly global coverage table stakes

## Detailed App Profiles

### 1. Flightradar24 — The Global Leader

**Position**: #1 flight tracking app in 150+ countries, 4M+ daily users
**Rating**: 4.5★ | **Pricing**: Free / Silver $2.99/mo / Gold $7.99/mo

**Key Features**:
- World's largest ADS-B network (50,000+ receivers)
- Real-time global flight map with aircraft icons
- AR Sky View (point at sky to identify flights)
- 3D cockpit/pilot perspective view
- 3D aircraft models with 100s of airline liveries (community-contributed)
- Detailed flight panel: callsign, route, ETA, ETD, progress bar, ground speed, altitude, vertical speed, squawk, GPS altitude, airspeed, wind, temperature, FIR/UIR, Mach
- Airport detail: arrivals/departures, delays, weather
- Filters by airline, aircraft type, altitude, speed, flight category (passenger/cargo/military)
- Flight history playback (90 days Silver, 365 days Gold)
- Airport ground vehicle tracking (unique feature)
- Weather layers (airports at Silver; clouds, precipitation at Gold)
- Aeronautical charts and oceanic tracks (Gold)
- ATC/FIR boundaries (Gold)
- Extended Mode S data (Gold)
- CSV/KML data export
- Home screen widgets
- Aircraft database of 500,000+ aircraft

**Unique differentiator**: Most comprehensive real-time data depth + community-driven content (3D models, receiver network)

### 2. FlightAware — The Data Powerhouse

**Position**: 12M+ users worldwide, owned by Collins Aerospace
**Rating**: 4.6★ | **Pricing**: Free (ad-supported) / Premium tiers

**Key Features**:
- Real-time plane tracking worldwide
- Flight status alerts (departure, arrival, cancellations, gate, delays, diversions)
- "Where is My Plane?" — track inbound aircraft for connection planning
- Flight search by number, city, airport
- Flight details: real-time status, times, gate/terminal, tail number, planned route
- Weather radar overlay
- Favorites (save aircraft and airports)
- iOS widgets for ADS-B receiver metrics
- Historical flight data archive back to 2006 (nearly 20 years)
- 3D pilot perspective view
- Nearby aircraft AR view
- AeroAPI developer platform (industry-leading)
- Foresight ML — predictive ETA using ML + historical data

**Unique differentiator**: Deepest historical data (since 2006), best developer API (AeroAPI), enterprise-grade Foresight predictions

## Data Sources & APIs

### Primary Data Sources Used by Top Apps

| Source | Type | Used By |
|--------|------|---------|
| ADS-B (1090MHz) | Crowdsourced ground receivers | All apps |
| Aireon Space-Based ADS-B | Iridium satellite constellation | FR24, FlightAware |
| Spire Space-Based ADS-B | Additional satellite ADS-B | FR24 |
| FAA SWIM | US government NAS data | FlightAware, Flighty, FlightStats |
| EUROCONTROL NM | European flight data | Flighty, FlightStats |
| FAA Radar | US/Canada radar | FR24, FlightAware |
| MLAT (Multilateration) | Position calculation from multiple receivers | FR24, FlightAware, Plane Finder |
| FLARM / Open Glider Network | Light aircraft tracking | FR24, Plane Finder |
| Airport Direct Feeds | Gate, terminal, baggage data | Flighty, FlightAware |
| Airline Data Feeds | Schedule and status data | FlightStats (Cirium), KAYAK |

## Competitive Gaps & Our Opportunity

### What No App Does Well (Our Opportunity)

1. **Unified best-of-breed experience**: No single app combines FR24's data depth + Flighty's intelligence + FlightStats' accuracy + byAir's import flexibility
2. **Modern iOS-native design with deep data**: FR24 has the data but dated iOS design; Flighty has the design but limited avgeek features
3. **AI airport experience**: Only byAir has AI airport guides; huge room for improvement
4. **Cross-platform travel wallet**: Combining tracking + boarding passes + airport info + lounge access in one elegant interface
5. **Privacy-first approach**: Most apps track heavily; opportunity for privacy-focused alternative
6. **Real-time turbulence**: Mostly absent from consumer apps, despite being the #1 passenger concern

### Our Target Position

```
SkyTrack = Flighty's intelligence + Flightradar24's data depth + Apple Design Award UX
```

Targeting the **premium traveler** who wants both accurate predictions AND deep aviation data, all in a beautifully designed iOS-native package.
